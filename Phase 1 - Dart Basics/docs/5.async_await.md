Phase 1 — Dart

15. async / await

From 14. Future, we learned:

Future<String>

means:

> "A String will be available later."



Now async and await are how we work with those Futures conveniently.

1. async

When a function performs asynchronous work, we mark it with async.

Future<String> getName() async {
  return 'Nayeem';
}

Notice something important:

Even though we return:

'Nayeem'

the function's return type is still:

Future<String>

Because an async function automatically returns a Future.


---

2. await

await means:

> "Wait for this Future to finish, then give me its actual value."



Example:

Future<String> getName() async {
  return 'Nayeem';
}

Future<void> main() async {
  final name = await getName();

  print(name);
}

Here:

final name = await getName();

getName() gives:

Future<String>

Then await waits for it and gives:

String

So:

getName()
    ↓
Future<String>
    ↓ await
String
    ↓
"Nayeem"


---

3. Why does main() also need async?

Because you cannot normally use await inside an ordinary synchronous function.

This:

void main() {
  final name = await getName(); // ❌
}

is invalid.

So we write:

Future<void> main() async {
  final name = await getName();
}

The async allows us to use await inside that function.


---

4. Let's add a delay

Now let's make it realistic:

Future<String> getName() async {
  await Future.delayed(Duration(seconds: 2));

  return 'Nayeem';
}

And:

Future<void> main() async {
  print('Getting name...');

  final name = await getName();

  print(name);
}

The flow is:

Getting name...
      ↓
 wait 2 seconds
      ↓
Nayeem

The important thing is that the asynchronous operation can complete later rather than requiring the program to freeze while waiting.


---

5. Multiple awaits

You can use several:

Future<void> main() async {
  final name = await getName();

  final age = await getAge();

  print(name);
  print(age);
}

For example:

Future<String> getName() async {
  await Future.delayed(Duration(seconds: 1));
  return 'Nayeem';
}

Future<int> getAge() async {
  await Future.delayed(Duration(seconds: 1));
  return 21;
}

The code reads almost like normal synchronous code:

get name
   ↓
wait
   ↓
get age
   ↓
wait
   ↓
print


---

6. async does NOT mean "run on another thread"

This is an important beginner point.

Don't think:

> async = another thread.



That's not what it means.

For now, think:

> async allows a function to work with asynchronous operations, and await lets us wait for a Future's result.



Later, when we study isolates, we'll talk about actual separate execution.


---

7. Future<void> + async

If the function doesn't return a useful value:

Future<void> saveData() async {
  await Future.delayed(Duration(seconds: 2));

  print('Data saved');
}

Then:

Future<void> main() async {
  await saveData();

  print('Finished');
}

Output:

Data saved
Finished

The await makes sure "Finished" happens after saveData() completes.


---

8. async + return value

This is worth remembering:

Future<int> getNumber() async {
  return 10;
}

You write:

return 10;

not:

return Future.value(10);

because async automatically wraps the returned value in a Future.

Conceptually:

10
 ↓
Future<int>


---

🧠 The three things together

You now have:

Future

> A value that will be available later.



async

> Marks a function as asynchronous and allows await inside it.



await

> Waits for a Future to complete and gives you its result.



So:

Future<String> getName() async {
  await Future.delayed(Duration(seconds: 2));

  return 'Nayeem';
}

And:

Future<void> main() async {
  final name = await getName();

  print(name);
}


---

🎯 Your mental model

Remember this:

Future<String>
     ↓
  "later"
     ↓ await
  String
     ↓
"Nayeem"

And:

async → "This function can use await."

await → "Give me the result of this Future."
