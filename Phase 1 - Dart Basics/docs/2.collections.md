Phase 1 — Dart

7. Collections

Dart has three collection types you need to become very comfortable with:

1. List → ordered collection


2. Set → unique values


3. Map → key-value pairs



These are extremely important in Flutter because you'll use them constantly when working with API data, UI lists, JSON, and application state.


---

1. List

A List stores multiple values in order.

List<String> fruits = ['Apple', 'Banana', 'Mango'];

You access items using their index:

print(fruits[0]); // Apple
print(fruits[1]); // Banana

Indexes start at 0.

So:

Apple   → 0
Banana  → 1
Mango   → 2

Adding items

fruits.add('Orange');

Adding multiple items

fruits.addAll(['Grapes', 'Watermelon']);

Removing

fruits.remove('Banana');

Or by index:

fruits.removeAt(0);

Length

print(fruits.length);


---

2. Looping through a List

You'll use this constantly.

for (String fruit in fruits) {
  print(fruit);
}

There's also forEach():

fruits.forEach((fruit) {
  print(fruit);
});

And the shorter version:

fruits.forEach((fruit) => print(fruit));

In Flutter, you'll eventually see similar callback syntax everywhere.


---

3. Set

A Set stores unique values.

Set<String> names = {'Nayeem', 'Rahim', 'Karim'};

If you try:

names.add('Nayeem');

there will still only be one Nayeem.

That's the main difference:

List → duplicates allowed
Set  → duplicates not allowed

For example:

List<int> numbers = [1, 2, 2, 3, 3, 3];

contains duplicates.

But:

Set<int> numbers = {1, 2, 2, 3, 3, 3};

effectively contains:

1, 2, 3

A Set is useful when you care about uniqueness.


---

4. Map

A Map stores key → value pairs.

Map<String, dynamic> user = {
  'name': 'Nayeem',
  'age': 21,
  'country': 'Bangladesh',
};

You access values using their keys:

print(user['name']);
print(user['age']);

Output:

Nayeem
21

You can add another key:

user['email'] = 'example@gmail.com';

And remove one:

user.remove('age');

Why Map matters for Flutter

This is especially important when you start working with JSON.

An API might return something conceptually like:

{
  "name": "Nayeem",
  "age": 21
}

When decoded in Dart, you'll commonly work with a Map.

We'll go much deeper into this when we reach APIs and JSON.


---

5. Important collection methods

You should become familiar with these:

where()

Filter values.

List<int> numbers = [1, 2, 3, 4, 5, 6];

final evenNumbers = numbers.where((number) => number.isEven);

print(evenNumbers);

Conceptually:

[1, 2, 3, 4, 5, 6]
          ↓
      filter even
          ↓
      [2, 4, 6]

map()

Transform each item.

final doubled = numbers.map((number) => number * 2);

Conceptually:

1 → 2
2 → 4
3 → 6
4 → 8
...

first

print(numbers.first);

last

print(numbers.last);

contains

print(numbers.contains(3));

Returns:

true


---

One important Dart concept

You'll often see:

final evenNumbers = numbers.where((number) => number.isEven);

Notice that we didn't explicitly write the type.

Dart can infer it.

This is called type inference.

Later, you'll see code like this constantly in Flutter.
