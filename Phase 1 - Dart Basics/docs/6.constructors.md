Phase 1 — Dart

10. Constructors

You already used constructors in the previous lesson:

class User {
  String name;
  int age;

  User(this.name, this.age);
}

So now let's understand what a constructor actually does and the different forms you'll encounter in Flutter.


---

1. What is a constructor?

A constructor is a special function used when you create an object.

User user = User('Nayeem', 21);

This part:

User('Nayeem', 21)

is calling the constructor.

A constructor's job is mainly to initialize the object.


---

2. Basic constructor

You can write it explicitly:

class User {
  String name;
  int age;

  User(String name, int age) {
    this.name = name;
    this.age = age;
  }
}

But Dart gives us a shorter syntax.

class User {
  String name;
  int age;

  User(this.name, this.age);
}

These accomplish the same thing.

What does this mean?

Inside a class, this refers to the current object.

So:

User(this.name, this.age);

basically means:

> Take the values passed to the constructor and assign them to this object's name and age.




---

3. Named parameters

This is extremely important in Flutter.

Instead of:

User('Nayeem', 21);

you can use:

class User {
  String name;
  int age;

  User({
    required this.name,
    required this.age,
  });
}

Now:

User user = User(
  name: 'Nayeem',
  age: 21,
);

This makes the code easier to understand.

You'll see this style everywhere in Flutter.

For example:

Container(
  width: 200,
  height: 100,
);

width and height are named parameters.


---

4. Default values

You can give a parameter a default value.

class User {
  String name;
  String country;

  User({
    required this.name,
    this.country = 'Bangladesh',
  });
}

Now:

User user1 = User(name: 'Nayeem');

will have:

name: Nayeem
country: Bangladesh

But you can override it:

User user2 = User(
  name: 'John',
  country: 'USA',
);


---

5. final properties + constructor

This pattern is extremely common in Flutter:

class Product {
  final String name;
  final double price;

  Product({
    required this.name,
    required this.price,
  });
}

Then:

final product = Product(
  name: 'Laptop',
  price: 80000,
);

Because the properties are final, you can't later do:

product.price = 90000; // ❌

This is a pattern you'll see constantly when creating models and Flutter widgets.


---

6. Named constructors

Dart also allows multiple constructors for the same class.

For example:

class User {
  final String name;
  final int age;

  User({
    required this.name,
    required this.age,
  });

  User.guest()
      : name = 'Guest',
        age = 0;
}

Now you have two ways to create a User:

final user1 = User(
  name: 'Nayeem',
  age: 21,
);

final user2 = User.guest();

User.guest() is called a named constructor.

This becomes useful when there are different meaningful ways to create an object.


---

7. const constructors

You'll see this a lot in Flutter.

A class can have a const constructor:

class Point {
  final int x;
  final int y;

  const Point(this.x, this.y);
}

Then:

const point = Point(10, 20);

The object can be created as a compile-time constant.

You'll eventually see Flutter code such as:

const Text('Hello');

Don't worry about the deeper performance/constant-evaluation details yet. The important thing for now is recognizing the pattern.


---

8. Constructor initializer list

You may eventually encounter:

class User {
  final String name;
  final int age;

  User(String name, int age)
      : name = name,
        age = age;
}

This is an initializer list.

It can also be used to calculate or validate values before the constructor body runs.

For example:

class Rectangle {
  final double width;
  final double height;
  final double area;

  Rectangle(this.width, this.height)
      : area = width * height;
}

Now:

final rectangle = Rectangle(10, 5);

print(rectangle.area);

Output:

50

You don't need to master initializer lists yet. Just understand what they are and recognize the syntax.


---

🧠 What I want you to remember

At this stage, focus on these four:

Normal constructor

User(this.name, this.age);

Named parameters

User({
  required this.name,
  required this.age,
});

Named constructor

User.guest();

Const constructor

const User(...);

These four patterns will appear repeatedly once we start Flutter.
