Lesson 6 — Functions in Dart

A function is a reusable piece of code that performs a specific task.

The simplest function:

void greet() {
  print('Hello!');
}

To run it:

greet();

1. Parameters

Functions can receive information:

void greet(String name) {
  print('Hello, $name!');
}

Calling it:

greet('Nayeem');

Output:

Hello, Nayeem!

Here:

String name is a parameter

'Nayeem' is an argument


2. Returning a value

A function doesn't always print something. It can return a value:

int add(int a, int b) {
  return a + b;
}

Then:

int result = add(10, 20);

print(result);

Output:

30

The int before add tells Dart that the function returns an int.

3. Arrow functions

For very small functions, Dart provides a shorter syntax:

int add(int a, int b) => a + b;

This is equivalent to:

int add(int a, int b) {
  return a + b;
}

You'll see arrow functions a lot in Flutter code.

For example:

Widget build(BuildContext context) => ...

Don't worry about Widget and BuildContext yet; we'll get there.

4. Optional positional parameters

You can make parameters optional:

void greet(String name, [String? message]) {
  print('$name: ${message ?? 'Hello'}');
}

Now both are valid:

greet('Nayeem');

greet('Nayeem', 'Good morning');

The [] means the parameter is optional.

5. Named parameters

Dart uses named parameters heavily, especially in Flutter.

void createUser({
  required String name,
  required int age,
}) {
  print('$name is $age years old');
}

Call it like this:

createUser(
  name: 'Nayeem',
  age: 20,
);

This is extremely important for Flutter because you'll constantly see code such as:

Container(
  width: 200,
  height: 100,
);

Those are named parameters.

6. required

required means the caller must provide the named parameter:

void login({
  required String email,
  required String password,
}) {
  // ...
}

This won't work:

login(email: 'test@gmail.com');

because password is required.

This does:

login(
  email: 'test@gmail.com',
  password: '123456',
);
