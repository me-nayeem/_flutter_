9. Classes & Objects

This is one of the most important Dart topics before moving deeply into Flutter.

The basic idea is:

> A class is a blueprint. An object is an actual thing created from that blueprint.



For example, imagine we want to represent a user.

1. Creating a class

class User {
  String name;
  int age;

  User(this.name, this.age);
}

Here we've defined a User class with:

name → property

age → property

User(...) → constructor


We'll study constructors more deeply in the next topic.


---

2. Creating an object

Now we can create an actual User:

User user1 = User('Nayeem', 21);

User is the class.

user1 is the object.

You can access its properties:

print(user1.name);
print(user1.age);

Output:

Nayeem
21

Think of it like:

Class
  ↓
User
 ┌───────────────┐
 │ name          │
 │ age           │
 └───────────────┘
       ↓
     Object
       ↓
 User('Nayeem', 21)


---

3. Methods

A class can also contain functions.

When a function belongs to a class, we usually call it a method.

class User {
  String name;
  int age;

  User(this.name, this.age);

  void introduce() {
    print('Hi, I am $name and I am $age years old.');
  }
}

Now:

User user = User('Nayeem', 21);

user.introduce();

Output:

Hi, I am Nayeem and I am 21 years old.

Notice that introduce() can directly access name and age.

That's because they're properties of the same object.


---

4. Each object has its own data

This is important.

User user1 = User('Nayeem', 21);
User user2 = User('Rahim', 25);

Now:

print(user1.name);
print(user2.name);

gives:

Nayeem
Rahim

They're both created from the same class, but they contain different data.


---

5. Changing properties

If a property isn't final, you can change it:

user1.age = 22;

print(user1.age);

Output:

22

You can also make a property immutable:

class User {
  final String name;
  final int age;

  User(this.name, this.age);
}

Now:

user1.age = 22; // ❌

because final means it can't be reassigned after initialization.


---

6. Why classes matter so much in Flutter

You'll constantly create classes to represent things such as:

User
Product
Message
Order
Movie
Weather
Article

For example, an API might give you:

{
  "name": "Nayeem",
  "age": 21
}

Eventually you'll turn that data into something like:

class User {
  final String name;
  final int age;

  User(this.name, this.age);
}

Then instead of passing around random Maps, you can work with:

User user

and write:

user.name
user.age

This becomes very important when we reach models, APIs, and architecture.


---

7. A class can contain behavior

A useful way to think about a class is:

Data + behavior

For example:

class BankAccount {
  double balance;

  BankAccount(this.balance);

  void deposit(double amount) {
    balance += amount;
  }

  void withdraw(double amount) {
    balance -= amount;
  }
}

Then:

BankAccount account = BankAccount(1000);

account.deposit(500);

print(account.balance);

Output:

1500

The object contains:

Data: balance

Behavior: deposit() and withdraw()


That's the fundamental idea behind object-oriented programming.


---

🧠 One distinction to remember

Don't confuse:

Class

class User {
  ...
}

with:

Object

User user = User('Nayeem', 21);

The class describes what a User is.

The object represents one particular User.
